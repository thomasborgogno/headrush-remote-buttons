Headrush Remote Buttons

A touch remote for Headrush pedalboards (scenes and footswitches) that runs in your browser. No app, no server to install.

Un telecomando touch per le pedaliere Headrush (scene e footswitch) che gira nel browser. Nessuna app e nessun server da installare.

Tested only on the Headrush Core. It may work with other models that have the same web editor (Flex Prime, Pedalboard), but that is untested.

Testato solo su Headrush Core. Potrebbe funzionare con altri modelli che hanno lo stesso editor web (Flex Prime, Pedalboard), ma non è stato provato.

1. Create the bookmarklet

1. Crea il segnalibro

Drag this button to your bookmarks bar (desktop), or press Copy, create a new bookmark and paste the copied text as its address (phone).

Trascina questo pulsante nella barra dei preferiti (computer), oppure premi Copia, crea un nuovo segnalibro e incolla il testo copiato come indirizzo (telefono).

2. Open your Headrush and tap the bookmark

2. Apri il tuo Headrush e tocca il segnalibro

Type your Headrush's IP address, open it in the same browser (phone and Headrush on the same network), then run the bookmark. The address is remembered on this device.

Scrivi l'indirizzo IP del tuo Headrush e aprilo nello stesso browser (telefono e Headrush sulla stessa rete), poi esegui il segnalibro. L'indirizzo viene ricordato su questo dispositivo.

OpenApri

Don't know the IP? This page can't search for it (browsers don't allow a secure page to scan your network). Look in the pedalboard's Wi-Fi/network settings, or in your router's list of connected devices (usually a device named "Headrush").

Non conosci l'IP? Questa pagina non può cercarlo (i browser non permettono a una pagina sicura di scansionare la tua rete). Guardalo nelle impostazioni Wi-Fi/rete della pedaliera, oppure nell'elenco dei dispositivi connessi del router (di solito un dispositivo chiamato "Headrush").

  • iPhone / iPad (Safari): open Bookmarks, tap the bookmark.
  • iPhone / iPad (Safari): apri i Preferiti e tocca il segnalibro.
  • Android (Chrome): type the bookmark's name in the address bar and pick it from the suggestions. Firefox lets you run it from the bookmarks menu.
  • Android (Chrome): scrivi il nome del segnalibro nella barra degli indirizzi e sceglilo dai suggerimenti. Firefox permette di eseguirlo dal menu dei segnalibri.
  • Desktop: click the bookmark.
  • Computer: clicca il segnalibro.

Security: read this

Sicurezza: leggi qui

  • The script runs inside your Headrush's own page with the same powers as the official editor. Only use a bookmarklet created on a page you trust, never one given to you by someone else.
  • Lo script gira dentro la pagina del tuo Headrush con gli stessi poteri dell'editor ufficiale. Usa solo un segnalibro creato su una pagina di cui ti fidi, mai uno che ti ha dato qualcun altro.
  • The bookmarklet pins the exact file by its hash (SRI): if the hosted file ever changes, the browser refuses to run it. The cost: after an update you must create the bookmarklet again from this page.
  • Il segnalibro fissa il file esatto con la sua impronta (SRI): se il file pubblicato cambia, il browser rifiuta di eseguirlo. Il prezzo: dopo un aggiornamento devi ricreare il segnalibro da questa pagina.
  • The app can only write scene and footswitch state (scene selection, A/B, latch, hold). It never saves, renames or deletes rigs. Nothing is sent anywhere: it only talks to your Headrush.
  • L'app può scrivere solo lo stato di scene e footswitch (selezione scena, A/B, latch, hold). Non salva, rinomina né elimina mai i rig. Non invia nulla altrove: parla solo con il tuo Headrush.
  • The Headrush has no password: anyone on your network can already control it. Unofficial project, not affiliated with Headrush.
  • L'Headrush non ha password: chiunque sulla tua rete può già controllarlo. Progetto non ufficiale, non affiliato a Headrush.

Limits

Limiti

  • You have to open the Headrush and run the bookmark each time. It can't be installed as an app (the Headrush page is plain HTTP).
  • Devi aprire l'Headrush ed eseguire il segnalibro ogni volta. Non si può installare come app (la pagina dell'Headrush è in HTTP semplice).
  • If a firmware update tightens the device's security policy, the script may stop loading.
  • Se un aggiornamento del firmware restringe la politica di sicurezza del dispositivo, lo script potrebbe non caricarsi più.
