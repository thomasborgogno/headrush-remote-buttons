Headrush Remote Buttons

A touch remote for the Headrush Core (scenes and footswitches) that runs in your browser. No app, no server to install.

Un telecomando touch per l'Headrush Core (scene e footswitch) che gira nel browser. Nessuna app e nessun server da installare.

1. Create the bookmarklet

1. Crea il segnalibro

Drag this button to your bookmarks bar (desktop), or press Copy, create a new bookmark and paste the copied text as its address (phone).

Trascina questo pulsante nella barra dei preferiti (computer), oppure premi Copia, crea un nuovo segnalibro e incolla il testo copiato come indirizzo (telefono).

2. Open your Core and tap the bookmark

2. Apri il Core e tocca il segnalibro

Open the Core's address in the same browser (phone and Core on the same network), then run the bookmark.

Apri l'indirizzo del Core nello stesso browser (telefono e Core sulla stessa rete), poi esegui il segnalibro.

Open the CoreApri il Core
  • iPhone / iPad (Safari): open Bookmarks, tap the bookmark.
  • iPhone / iPad (Safari): apri i Preferiti e tocca il segnalibro.
  • Android (Chrome): type the bookmark's name in the address bar and pick it from the suggestions. Firefox lets you run it from the bookmarks menu.
  • Android (Chrome): scrivi il nome del segnalibro nella barra degli indirizzi e sceglilo dai suggerimenti. Firefox permette di eseguirlo dal menu dei segnalibri.
  • Desktop: click the bookmark.
  • Computer: clicca il segnalibro.

Security: read this

Sicurezza: leggi qui

  • The script runs inside the Core's page with the same powers as the official editor. Only use a bookmarklet created on a page you trust, never one given to you by someone else.
  • Lo script gira dentro la pagina del Core con gli stessi poteri dell'editor ufficiale. Usa solo un segnalibro creato su una pagina di cui ti fidi, mai uno che ti ha dato qualcun altro.
  • The bookmarklet pins the exact file by its hash (SRI): if the hosted file ever changes, the browser refuses to run it. The cost: after an update you must create the bookmarklet again from this page.
  • Il segnalibro fissa il file esatto con la sua impronta (SRI): se il file pubblicato cambia, il browser rifiuta di eseguirlo. Il prezzo: dopo un aggiornamento devi ricreare il segnalibro da questa pagina.
  • The app can only write scene and footswitch state (scene selection, A/B, latch, hold). It never saves, renames or deletes rigs. Nothing is sent anywhere: it only talks to your Core.
  • L'app può scrivere solo lo stato di scene e footswitch (selezione scena, A/B, latch, hold). Non salva, rinomina né elimina mai i rig. Non invia nulla altrove: parla solo con il tuo Core.
  • The Core has no password: anyone on your network can already control it. Unofficial project, not affiliated with Headrush.
  • Il Core non ha password: chiunque sulla tua rete può già controllarlo. Progetto non ufficiale, non affiliato a Headrush.

Limits

Limiti

  • You have to open the Core and run the bookmark each time. It can't be installed as an app (the Core's page is plain HTTP). For an installable app, run the server version from the repository.
  • Devi aprire il Core ed eseguire il segnalibro ogni volta. Non si può installare come app (la pagina del Core è in HTTP semplice). Per un'app installabile usa la versione con server del repository.
  • If a firmware update tightens the Core's security policy, the script may stop loading.
  • Se un aggiornamento del firmware restringe la politica di sicurezza del Core, lo script potrebbe non caricarsi più.
