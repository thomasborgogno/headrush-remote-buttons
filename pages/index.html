Headrush Remote Buttons

A touch remote for Headrush pedalboards (scenes and footswitches) that runs in your browser. No app, no server to install.

Tested only on the Headrush Core. It may work with other models that have the same web editor (Flex Prime, Pedalboard), but that is untested.

1. Create the bookmarklet

Drag this button to your bookmarks bar (desktop), or press Copy, create a new bookmark and paste the copied text as its address (phone).

Headrush Remote Buttons

2. Open your Headrush and tap the bookmark

Type your Headrush's IP address, open it in the same browser (phone and Headrush on the same network), then run the bookmark. The address is remembered on this device.

Open

Don't know the IP? This page can't search for it (browsers don't allow a secure page to scan your network). Look in the pedalboard's Wi-Fi/network settings, or in your router's list of connected devices (usually a device named "Headrush").

  • iPhone / iPad (Safari): open Bookmarks, tap the bookmark.
  • Android (Chrome): type the bookmark's name in the address bar and pick it from the suggestions. Firefox lets you run it from the bookmarks menu.
  • Desktop: click the bookmark.

Security: read this

  • The script runs inside your Headrush's own page with the same powers as the official editor. Only use a bookmarklet created on a page you trust, never one given to you by someone else.
  • The bookmarklet pins the exact file by its hash (SRI): if the hosted file ever changes, the browser refuses to run it. The cost: after an update you must create the bookmarklet again from this page.
  • The app can only write scene and footswitch state (scene selection, A/B, latch, hold). It never saves, renames or deletes rigs. Nothing is sent anywhere: it only talks to your Headrush.
  • The Headrush has no password: anyone on your network can already control it. Unofficial project, not affiliated with Headrush.

Limits

  • You have to open the Headrush and run the bookmark each time. It can't be installed as an app (the Headrush page is plain HTTP).
  • If a firmware update tightens the device's security policy, the script may stop loading.
